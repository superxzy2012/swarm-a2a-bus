## 1. 策略假设（单一假设）

**假设**: **动量反转策略**——在 A 股主板（沪深300 成分股）中，过去 20 个交易日累计收益排名前 20% 的股票，在未来 5 个交易日内存在均值回归倾向，做空前 20%、做多后 20% 构建多空组合，可获取超额收益。

**选因子逻辑**: 短期动量反转（Short-term Reversal）在学术文献与 A 股实证中均有记录，且与 C3 数据治理骨架的“样本外切分/前视偏差审计”天然契合——需严格 shift(1) 与 PIT 数据验证。

## 3. 回测方案（全要素）

| 要素 | 设定 | 备注 |
|------|------|------|
| **手续费** | 万分之 2.5（双边），含佣金+过户费+规费 | A 股主板标准费率 |
| **滑点** | 单边 1 bp（相对 T+1 开盘价） | 以开盘价成交为基准，模拟冲击成本 |
| **印花税** | 卖出侧 0.1%（千分之一） | 仅卖出收取，按成交额计 |
| **交易限制** | - 单只股票单日成交额不超过该股当日成交量 10%<br>- 单只持仓权重上限 5%（多空各腿）<br>- 涨跌停板不可成交（以 T+1 开盘价判断）<br>- ST/*ST/退市风险警示股剔除 | 硬约束，违规信号自动降权至 0 |
| **调仓频率** | 日频调仓（每日收盘重算信号，次日开盘换仓） | 换仓率预估 30-40%/日 |
| **样本外区间** | **Walk-Forward 窗口**: 训练 252 日 → 验证 63 日 → 滚动步长 21 日<br>**Expanding Window**: 累积训练 → 固定验证 63 日<br>**TimeSeriesSplit**: n_splits=5, test_size=63, gap=5（horizon 缓冲） | 三套切分并跑，取最保守指标 |
| **过拟合检查** | 1) **组合测试**: 训练集 IC 均值 > 0.02 且 样本外 IC 均值 > 0<br>2) **置换检验**: 随机打乱标签 1000 次，原策略 Sharpe 超过 95 分位<br>3) **参数敏感性**: lookback 15/20/25、持仓 3/5/7 日，样本外 Sharpe 方向一致<br>4) **Purged K-Fold**: gap=horizon(5) 禁止信息泄露 | 全部通过才判 PASS |
| **基准** | 沪深300 指数（全收益版，含股息再投资） | 超额收益 = 策略 - 基准 |

## 4. 样本外切分设计（符合 C3 骨架 §2）

```python
# 伪码：C3 split_train_val_test 接口
from pkg.c3_data_gov import split_train_val_test

splits = split_train_val_test(
    data=panel,                    # MultiIndex (date, symbol) 面板
    method="walk_forward",         # 兼容 expanding / timeseriessplit
    train_window=252,              # 约 1 年
    val_window=63,                 # 约 1 季度
    step=21,                       # 月度滚动
    horizon_buffer=5,              # gap=horizon，防前视
    purge=True,                    # Purged K-Fold
    embargo_pct=0.01               # 1% 禁入期
)
```

**输出**: 每个 fold 产出独立的 `train_idx / val_idx / test_idx`，交由建模流程严格分离 fit/transform。

## 6. 幸存者偏差与前视偏差审计（符合 C3 骨架 §4/§5）

| 审计项 | 实施方式 | 通过标准 |
|--------|----------|----------|
| **全市场快照** | 每个调仓日导出全 A 股（含退市/ST）快照，非沪深300 成分股亦保留 | 样本覆盖率 ≥ 98% |
| **点位时刻成分股** | 以调仓日收盘后公告的新名单为准，T+1 生效 | 无“未来名单提前用” |
| **永久标识符映射** | 统一用 `symbol`(6位代码) + `list_date`/`delist_date` 建映射 | 无代码复用导致的错配 |
| **上市满 60 天** | 新股上市前 60 个交易日强制剔除 | 100% 执行 |
| **shift(1) 强制** | 所有特征/标签生成均 `df.shift(1)`，标签 `horizon>=1` | 代码级静态检查（grep 无裸 `df[`） |
| **PIT 数据** | 财务字段以“披露日”而非“报告期”对齐 | AkShare 提供披露日字段，逐字段核对 |
